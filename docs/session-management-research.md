# Session Management Research — Enterprise IAM

## Seed Prompt

Research session management patterns for enterprise IAM systems.
Focus on: active session tracking, max concurrent sessions enforcement,
auto-expiration of inactive sessions, session revocation, and admin
monitoring dashboards. Include Spring Boot + Redis implementation patterns.

## Research Goals

1. How do enterprise IAM systems track and limit concurrent sessions?
2. What are best practices for session auto-expiration (idle timeout)?
3. How to implement admin session monitoring and bulk revocation?
4. Redis-based session store patterns with Spring Security.
5. Session clustering and replication strategies.

## Technology Scope

Spring Boot, Kotlin, Redis, PostgreSQL, JWT
