## 2. Cache Data Patterns (auth-service)

### Cached Data Types

| Cache Name | Data Type | Structure |
|------------|-----------|-----------|
| `permissions` | `List<String>` | List of permission strings by user+tenant |
| `roles` | `List<String>` | List of role names by user+tenant |
| `i18n-messages` | `MessageFormat?` | Cached i18n message by code+locale |

### Cache Key Pattern

```kotlin
// Current (custom) — from MultiTierPermissionCache
data class CacheKey(val userId: Long, val tenantId: Long)
// Key format: "perm:{userId}:{tenantId}" or "role:{userId}:{tenantId}"

// Target (@Cacheable) — Spring cache key 
// @Cacheable(cacheNames=["permissions"], key="#userId + ':' + #tenantId")
```

## 3. Request/Response DTOs (auth-service, context only)

### Auth DTOs
- `LoginRequest` — username, password, tenantId, deviceId
- `LoginResponse` — accessToken, refreshToken, user info
- `TokenRefreshRequest` — refreshToken
- `TokenRefreshResponse` — new accessToken

### RBAC DTOs
- NOT DETECTED — RBAC controllers use domain models directly
