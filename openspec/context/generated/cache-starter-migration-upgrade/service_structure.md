## 4. Architecture Pattern

**Clean Architecture layers (auth-service)**:
- `domain/` — Pure domain models, no framework dependencies
- `application/` — Use cases, ports, command/query handlers
- `adapter/in/` — Inbound (web controllers, Kafka consumers)
- `adapter/out/` — Outbound (persistence, cache, HTTP clients)

**base-cache-starter**:
- Spring Boot auto-configuration pattern
- `@ConfigurationProperties` for type-safe config
- `@ConditionalOnClass` for optional dependencies
- `ObjectProvider` for graceful degradation
