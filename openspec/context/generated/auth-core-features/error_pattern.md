# Error Pattern — auth-core-features

> Generated by Phase B code scan. All entries are evidence-based.

## Exception Hierarchy

```
AuthException (open class)                    → HttpStatus + errorCode
├── ResourceNotFoundException                  → 404 NOT_FOUND
├── DuplicateResourceException                → 409 CONFLICT
├── PermissionDeniedException                  → 403 FORBIDDEN
├── WriteNotAllowedException                  → 403 FORBIDDEN
├── AccountLockedException                    → 423 LOCKED
├── InvalidCredentialsException               → 401 UNAUTHORIZED
├── TokenExpiredException                     → 401 UNAUTHORIZED
└── PolicyEvaluationException                 → 403 FORBIDDEN
```
